# Install

```bash
sudo bash install.sh
```

Environment variables:

- `PANEL_PORT`: backend port, default `3000`
- `DEFAULT_ADMIN`: initial admin username, default `admin`
- `DEFAULT_PASSWORD`: initial admin password, default `changeme123`

Core installers:

```bash
sudo bash scripts/install-core/install-xray.sh
sudo bash scripts/install-core/install-realm.sh
sudo bash scripts/install-core/install-gost.sh
sudo bash scripts/install-core/install-singbox.sh
```
